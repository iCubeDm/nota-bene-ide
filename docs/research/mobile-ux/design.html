Nota Bene for Android: the agreed design

One consistent board of what review 1 settled (review-1.md, rounds 1–4). Every screen here follows the same rules; the current app and the history of the proposals stay in flows.html, whose screen numbers appear as “was …”. Darcula theme, English interface, 360 dp wide. Drawings approximate spacing; texts, order of controls and states are exact.

The rules every screen follows

  • Header pill: avatar, title, and a second line that says what the session is doing, as a messenger says “typing…” or “last seen”. A tap opens the window sheet (mode, model, Clear, Restart). There is no status bar under the tabs in any state.
  • Context ring: a 40 dp circle right of the pill with the context percent inside; primary below 70 %, accent from 70 %, red from 90 %. A tap opens the context sheet: context, plan limits, cost, Compact, Stats.
  • Mode: written under “Chat” in the tab pill, red for modes without prompts; changed only in the window sheet.
  • Message field: attach and mic inside it. Typing hides attach and turns the mic into Send, also inside. Stop is a grey 44 dp button 12 dp above Send, only while a turn runs. The hint is always “Message”.
  • Comments by paragraph: a tap on a paragraph is the only target; no selection inside it. Labels bubble above, Comment / Pin / Copy below.
