# Protocol schema and Dart types Implementation Plan

**Goal:** A JSON Schema generated from the existing types in `shared/src/protocol.ts`, Dart types generated from that schema in a pure Dart package, shared fixtures both sides round-trip, and a CI job that fails when either output is stale (#85).

**Approach:** `scripts/gen-protocol.ts` runs `ts-json-schema-generator` 2.9.0 over `shared/src/protocol.ts` for three roots (`ClientMessage`, `ServerEvent`, `UsageReport`) and writes `shared/schema/protocol.schema.json`. A generator of our own (`scripts/protocol/dart.ts`) turns that schema into Dart 3 sealed classes in `mobile/protocol/lib/src/protocol.g.dart`. `shared/fixtures/protocol.json` holds samples of every variant: Vitest validates them (ajv 8) against the schema and the TypeScript parser, `dart test` round-trips them. `--check` regenerates in memory and fails on any difference.

**Spec:** `docs/superpowers/specs/2026-11-07-remote-prototype-design.md` (section "What goes through the channel", "Schema source").

## Constraints

- `shared/src/protocol.ts` is only read, not restructured.
- The schema covers the messages the app uses; a type that does not convert cleanly is written by hand (a named constant with a comment saying why) and checked against the parser's fixtures.
- Generation runs in CI and fails on a stale output.
- New dev dependencies pinned to exact versions. Neutral fixtures (`/proj`, `src/a.ts`, made-up ids). No network, no ports.
- Prerequisite: the Dart SDK (`brew install dart-sdk`, or Flutter, needed for #88 anyway) installed with the author's consent before Task 3.
- Branch `gh-85-protocol-schema`; PR closes #85, squash.

## Review focus

1. An unknown event `kind`, agent event `t` or enum value yields an unknown variant or `$unknown`, never an exception.
2. An absent optional field (`force?`) stays absent; a required `null` (`session.title`) stays `null`.
3. `replay.events` nests whole `ServerEvent`s; nested items parse to their own variants.
4. Forgetting to regenerate: `--check` exits 1, names the stale file and the fixing command.
5. A new variant without a fixture: the coverage test names the missing discriminator value.

## Contracts

- `ROOTS = ['ClientMessage','ServerEvent','UsageReport']`. `ProtocolSchema = { $schema: draft-07; 'x-protocol': number; definitions }`, every root and everything it reaches under `definitions`; `x-protocol` equals `PROTOCOL` (13 at the time). `serialize` gives stable key order, two-space indent, trailing newline. `generate(): Map<path, text>`; `check(files, root): string[]` returns stale or missing paths.
- Generator options: `topRef: false`, `expose: 'export'`, `jsDoc: 'extended'`, `additionalProperties: true` (a newer peer may add fields; reverse skew must not fail). JSDoc kept as documentation for Dart.
- Fixtures shape `{ "client": [], "server": [], "usage": [] }`. They must include: a `send` without `force`, a `session` event with `title: null`, a `replay` holding a `user` and an agent `message` event, a `comments` event with a text, a media (with `time` and a `pen` shape) and a page anchor, a `MediaShape` of `kind: 'ellipse'`.
- Coverage test: every `type` of `ClientMessage`, `kind` of `ServerEvent` and `t` of `WireAgentEvent` (agent events inside `{kind:'agent', e}` and `replay.events`) appears in the fixtures.

**Dart emission** (header `// GENERATED by scripts/gen-protocol.ts from shared/src/protocol.ts. Do not edit.`, `const int protocolVersion = <x-protocol>;`; every class has `fromJson(Map<String,Object?>)` and `toJson()`; enums `static fromJson(Object?)` and `toJson()`; named definitions keep TypeScript names). Mapping decisions:
- **Object** -> `final class`, camelCase fields, JSON keys kept. Required and not nullable -> non-null; not required -> nullable and `toJson` omits it when null; required nullable is always written, `null` included.
- **Discriminated union** (a `const`/string enum property in every variant: `type`, `kind`, `t`) -> `sealed class` plus `<Union><ValuePascal>` (`ServerEventHello`); a variant with several discriminator values is joined with `Or` (`MediaShapeRectOrEllipse`) and keeps the field. Unknown or missing value -> `<Union>Unknown`, keeping the raw map and returning it from `toJson`.
- **Union where one object variant lacks the discriminator** (`Anchor`: `TextAnchor` has no `kind`) -> same sealed class; a map without the discriminator parses as that variant.
- **String enum** -> Dart `enum` with lowerCamelCase of the wire value (`codex-read-only` -> `codexReadOnly`; non-identifier characters become `_`, prefix `v` if not starting with a letter: `v_ff3b30`, `image_png`; two values on one name make the generator throw) plus last member `$unknown`. Unknown string -> `$unknown`; `toJson` of `$unknown` throws `StateError`.
- `T | null` -> `T?`; `number` -> `num`, `integer` -> `int`, `boolean` -> `bool`; array -> `List<T>`; tuple (`ModelCamera.position`) -> `List<num>`; `additionalProperties` only -> `Map<String,V>`; empty schema -> `Object?`.
- Anonymous nested objects and enums are named `<Parent><Property>` (`StatsContext`), `Item` appended for array items; intersections arrive merged.
- Anything else: `schemaToDart` throws naming the definition and JSON pointer; no silent `Object?`.
- Deterministic (definitions sorted by name) and `dart format`-clean, so CI can run `dart format --set-exit-if-changed`. A formatter difference is fixed in the generator, never by hand-editing the output.

## Tests

- `schema.test.ts`: roots and reached definitions present (`Comment`, `Anchor`, `WireAgentEvent`), no dangling `$ref`, version carried, deterministic.
- `fixtures.test.ts`: every fixture validates; the parser takes every client fixture as is (`parseClientMessage` deep-equals); coverage.
- `gen.test.ts`: check passes on fresh output; names a stale or deleted file (schema and Dart).
- `dart.test.ts` on small hand-made schemas: optional and required-nullable fields; union with unknown variant; one variant lacking the discriminator; enum with `$unknown`; several discriminator values; unsupported shape (`oneOf` string/number) throws with the definition name; the real schema converts (contains `protocolVersion = 13`, `sealed class ServerEvent`, `ServerEventReplay`, `List<ServerEvent> events`).
- Dart `protocol_test.dart`: every fixture round-trips; nested replay parses to own variants; unknown kind kept as `ServerEventUnknown` and re-serialized; unknown enum value is `$unknown`; absent stays absent, null stays null.
