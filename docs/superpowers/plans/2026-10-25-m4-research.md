# M4 research: prototype behaviour to match

The prototype lives in `prototype/server.mjs` (S) and `prototype/public/index.html` (H); line numbers are as of 2026-10-25. SDK 0.3.310 exposes every API below. Where a string is long, only the English text is kept here: the Russian one is in the prototype's `STR` (H).

## 1. Session picker
- `GET /sessions` (S:380-391): `listSessions({limit: 300})` across all projects, returns `{current, root, sessions: [{id, title: titleOf(x)||'', at: lastModified, size: fileSize, cwd: x.cwd || cwdOf(id)}]}`. Entries without a cwd are dropped (cannot be resumed in the right folder).
- `titleOf` (S:146): first of `customTitle`, `summary`, `firstPrompt` that is non-empty and does not start with `/`.
- `cwdOf` (S:126-144): finds `~/.claude/projects/*/<id>.jsonl`, reads the first 262144 bytes, regex `/"cwd":("(?:[^"\\]|\\.)*")/`, JSON-parses the match; cached in a Map, null included.
- UI (H:1401-1450): menu 460 px wide; this project first (`.here` header), other folders in first-appearance order; first item `newHere`; item = title or `untitled` plus meta `id8 · ago(at) · kb(size)`; current item gets ` · open now` and is not clickable; autofocused filter matches substrings of `(title+' '+cwd).toLowerCase()`, never hides the "new" item, hides empty groups.
- `ago`: under 1 min justNow, under 60 min minAgo(m), under 1440 min hAgo(round(m/60)), else a date (`day:'numeric', month:'short'`). `kb`: above 1e6 bytes `x.x MB`, else rounded KB. `short()` replaces `/Users/<x>` with `~`.
- i18n (ru / en):
  - sessions: Сессии / Sessions
  - sessTip: "Open another Claude Code session, from any folder (like claude --resume)"
  - openQ(t): «Открыть сессию «${t}»?» / "Open session “${t}”?"
  - newQ: «Начать новую сессию?» / "Start a new session?"
  - moveQ(dir): "This session is from another folder: the window will switch to the project ${dir} (file tree, file access and the agent's working folder)."
  - switchWarn: rewrite for the in-process switch, keep the second sentence: "Don’t keep this same session open in a terminal claude: the history would get mixed up."
  - switching: переключение… / switching…; switchFail: «Не удалось переключить: » / "Could not switch: "; loading: загрузка… / loading…
  - untitled: (без названия) / (untitled); openNow: « · открыта сейчас» / " · open now"
  - sessFilter: «Поиск по названию или папке…» / "Search by title or folder…"
  - newHere: «+ новая сессия в этом проекте» / "+ new session in this project"; thisProject: «этот проект · » / "this project · "
  - justNow: только что / just now; minAgo: «${m} мин назад» / "${m} min ago"; hAgo: «${h} ч назад» / "${h} h ago"; mb/kb: МБ/КБ / MB/KB

## 2. Titles
- Server: `title = titleOf(await getSessionInfo(id, {dir: root}))`, refreshed with stats, null on `conversation_reset`.
- Web: chat tab label is the title or `t('chat')`, tooltip `title ?? chatTip`; document title `${title ? title+' · ' : ''}${project} · Nota Bene`; header shows `${model} · ${id8}` (model from `system/init`).

## 3. Meters
- Context: `getContextUsage({detail:'summary'})`, 10 s timeout, gives `{used: totalTokens, max: rawMaxTokens || maxTokens, pct: percentage}`.
- Limits: `usage_EXPERIMENTAL_MAY_CHANGE_DO_NOT_RELY_ON_THIS_API_YET({skipBehaviors:true})`, 15 s timeout, throttled to once per 60 s. `cost = session.total_cost_usd`; `limits = rate_limits_available ? {five_hour, seven_day} : null`, each `{utilization (percent), resets_at (ISO)}`.
- Schedule: first refresh 1.5 s after start, then every 5 min (also resets the throttle), and after every `result`, `conversation_reset`, `compact_boundary`.
- `rate_limit_event`: when `rate_limit_info.rateLimitType` is `five_hour`/`seven_day` and utilization is not null, `pct = u<=1 ? u*100 : u`, `resets_at = resetsAt ? ISO(resetsAt*1000) : null`; merge it in.
- `fmtK(n) = n>=1e6 ? (n/1e6).toFixed(1)+'M' : n>=1e3 ? Math.round(n/1e3)+'k' : String(n)`. Bar 44x4 px, `warn` at 60, `hot` at 85. Cost shows only when there are no limits.
- i18n: ctx контекст / context; ctxTip(u,m) "${u} of ${m} tokens — auto-compact after that"; h5 5ч / 5h; h5Tip "5-hour plan limit"; week неделя / week; weekTip "weekly plan limit"; costTip "API cost of this session"; resets(at) «сброс ${at}» / "resets ${at}" with `at` formatted `{weekday:'short', hour:'2-digit', minute:'2-digit'}`.

## 4. Compact and clear
- Client sends `{type:'command', name}`. Server broadcasts a user event with text `'/'+name` and pushes the plain string into the input stream with `priority 'next'`.
- `conversation_reset`: clears history, saves the new id, title null, refreshes stats. Web: clears the feed and adds `cleared(at)`; on `compact_boundary` adds `compacted(fmtK(pre_tokens), at)`.
- i18n (en; ru in the prototype):
  - compactTip: "Compact context — the agent summarizes the conversation and continues from the summary (/compact)"
  - clearTip: "Clear context — start a fresh conversation (/clear). The current session stays in “Sessions ▾”"
  - clearQ: "Clear the context and start a new conversation?\n\nThe current session is kept — reopen it from “Sessions ▾”."
  - compacted(pre,at): "⇣ context compacted · was ${pre} tokens · ${at}"
  - cleared(at): "○ new conversation · context cleared · ${at}"

## 5. Plan card
- Detection: a permission event with `toolName === 'ExitPlanMode' && input.plan`.
- Look: teal border `oklch(0.78 0.12 185/.7)`; plan is rendered markdown, max-height 60vh, scrollable, commentable.
- Answer: both buttons send `{type:'permission', id, allow, input}`; the server answers `{behavior:'allow', updatedInput: input}`.
- Mode restore: entering plan from X records X; approving sets `restoreAfterPlan = X`; on the next non-plan echo that differs from it the client sends `mode X` once.
- i18n: planQ «План готов — утвердить?» / "Plan ready — approve?"; approvePlan(m) «Утвердить · дальше «${m}»» / "Approve · continue in “${m}”"; keepPlanning «Доработать план» / "Keep planning".

## 6. Mode
- `MODES = ['default','acceptEdits','plan','auto']`. A change calls `setPermissionMode(mode)` and is echoed as `{kind:'mode'}`; the server follows a `system` `init`/`status` whose `permissionMode` differs.
- Pill colours: acceptEdits primary, plan teal 185, auto yellow 80. Menu 340 px, opens above the pill, current mode marked.
- i18n (en; ru in the prototype): modeTip "Agent mode · Shift+Tab in the message field — next";
  - default (Обычный) "Asks before edits and commands";
  - acceptEdits (Принимать правки) "Edits files without asking, asks before commands";
  - plan (План) "Only reads and thinks, changes nothing; ends with a plan to approve";
  - auto (Авто) "A classifier approves safe actions itself, asks about the rest".

## 7. Suggestions
- SDK option `promptSuggestions: true` yields `{type:'prompt_suggestion', suggestion}`.
- Shown as the placeholder only when the field is empty and the agent not busy; opacity .45, padding-right 64 px, plus a `Tab ⇥` badge while shown. Tab fills the field. Any user event (replayed included) and `conversation_reset` clear it.

## 8. Favicon
- `FAV = {idle:'#8b6cf2', work:'#8b6cf2', workHi:'#f0761f', wait:'#e5484d', done:'#22b45a'}`.
- SVG 32x32: circle (16,16) r=15.5; white strokes width 2.8, round caps and joins; N `M7.5 21.5v-11l6.5 11v-11`; B `M18 10.5h3.2a2.75 2.75 0 0 1 0 5.5H18z` and `M18 16h3.7a2.75 2.75 0 0 1 0 5.5H18z`.
- Priority: wait (unanswered permission); work (busy, blinking every 700 ms between workHi and work); done (a live result arrived while `document.hidden || !hasFocus()`, cleared on focus or visibility); idle.

## 9. Toasts
- Dedup key `title+'\n'+msg`; a repeat shows ` xN` and restarts the 15 s timer; hover clears the timer; close button closes.
- Fixed at top 56 px, right 16 px, 380 px wide, `<pre>` capped at 160 px. Title `serverError(w)`: «Ошибка сервера · ${w}» / "Server error · ${w}".

## 10. Restart
In the prototype `POST /restart` exits with code 75 and `ide.sh` relaunches with `--continue`. The rebuild restarts in-process instead (ruling R-M4-1). i18n: restart «↻ Сервер» / "↻ Server"; restarting перезапуск… / restarting…; restartTip rewritten: «Перезапустить агента и продолжить ту же сессию» / "Restart the agent and continue the same session".

## 11. Background-task line
- `system` messages with a `task_(started|progress|updated|notification)` subtype go to `onTask`; `background_tasks_changed` is not used.
- Map `task_id -> {desc, type, start, tokens, tool, summary}`:
  - started: skipped if `ambient || skip_transcript`; `desc = description || subagent_type || task_type || 'task'`; `start` = event ts;
  - progress: `tokens = usage.total_tokens`, `tool = last_tool_name`, `summary`;
  - updated: deleted if status is not running/pending/paused, else desc from `patch.description`;
  - notification: deleted.
- Row: pulsing gear + desc + `time · fmtK(tokens) tok · tool`; time `Ns` under 60 s else `m:ss`; tooltip is the summary or desc. A 1 s interval runs only while tasks are live. Replay clears the list first and does not render during replay.
