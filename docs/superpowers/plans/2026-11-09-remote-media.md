# Images and video with markup in the app (#90) Implementation Plan

**Goal:** On the phone, open an image or video of the project from the chat, draw on it (rectangle, ellipse, arrow, pen; the desktop's five colours), comment and send: the agent gets the same batch and frame image the desktop would send. A video plays from the host through the channel with Range.

**Approach:** The media anchor and its files are the desktop's (`web/src/media/markup`): shapes relative to natural size, `frame.jpg` + `layer.png` written to `/marks/<comment id>/`, the downscaled frame posted to `/attach` and kept as the comment's only generated image (`genImages: 1`). The batch text gains the desktop's media branch (`composeBatch`, `whereOf`) with strings generated from `web/src/i18n` as templates. Comments with images are now sent from the phone too, labelled as the desktop labels them. A video plays in `video_player` from a loopback HTTP proxy that forwards each request (Range included) as a streamed `http` stream of the channel; the frame to mark comes from Android's `MediaMetadataRetriever` through the same proxy at the paused time.

**Spec:** `docs/superpowers/specs/2026-11-07-remote-prototype-design.md` (media work; `/file` with Range; loopback endpoint for video; media anchors).

## Decisions

- Branch `gh-90-media` from `remote`, PR into `remote`, squash, commits `gh-90: ...`. Six ARB languages. Tests only on ports 4790-4795.
- No protocol or server change; comments pass `isComment`.
- The batch text is the desktop's character for character for the cases the phone produces (checked against a fixture the desktop writes). Several comments on one frame are not merged into a composite image: each sends its own frame, the desktop's own fallback.
- Images `png jpg jpeg gif webp bmp` up to 32 MiB; videos `mp4 mov webm m4v`, streamed, no cap.
- The loopback proxy listens on 127.0.0.1 only, random port, random path token; Android cleartext allowed for 127.0.0.1 only (network security config, base config off).
- A failure while making a media comment (frame missing, `/marks` or `/attach` refused, channel gone) deletes `/marks/<id>`, adds nothing and says so; the drawing stays for retry.
- Video: a seek past the buffered part uses Range and gets 206; leaving the screen closes the channel streams; a vanished host shows an error, not a forever spinner.

## Contracts

- `lib/media/shapes.dart`, checked against the desktop by `web/src/media/markup/mobileParity.test.ts` (writes `mobile/app/test/fixtures/media/shapes.json`): `jsNum(v)` (JS `String(v)` formatting), `describeShape`, `mediaTime` (as `geometry.ts`), `strokeWidth`, `paintShapes` (as `drawShapes`: round caps/joins, arrow head 25 degrees, `max(12, 4*lineWidth)`), `simplify(points, eps = 0.0015)` and `penPoints` (eps doubled from 0.003 while over `penMaxValues = 20000`), `markColors = ['#ff3b30','#ffcc00','#34c759','#0a84ff','#ffffff']`, `containBox`, `toRel` (clamped 0..1), `rectFrom`.
- Batch: `batchTemplate(key, lang, args)` fills `{0}`,`{1}` of templates generated by calling the web function with placeholders (`imgLabel`, `imgLabelC`, `imgRef`, `imgRefMedia`, `filesLine`, `scaledSfx`) or plain strings (`markStale`, `batchHead`, `srcChat`); list args are joined with `, `. `composeSend(general, items, lang, {staleOf})` returns `{text, images}`, numbering images as `sendNow` does (a media comment's frame, then pasted ones), labels `imgLabelC(k, i+1)`, `mediaType: image/png`. `Comments.sendable` now includes media comments and text ones with images. `Comments.add(anchor, text, label, {id, images, genImages})`. `WindowTab.fileVersions` (path to last ETag) feeds `staleOf`. Fixture `mobile/app/test/fixtures/batch/media.json` from `web/src/comments/mobileBatch.test.ts` covers text, pasted images, media on image, media on video with time/scale/stale, in six languages.
- Streaming: `Channel.httpStream(port, method, path, {headers})` returns `({status, headers, body, cancel})`; the body pauses the mux stream (no credit) while its listener pauses; `cancel` closes the stream (`CLOSE` 1000); `http` is rebuilt on it. `MediaProxy.start(open)` (`lib/media/proxy.dart`): one file per proxy; GET/HEAD forward `range`, `if-range`, `if-none-match`, `accept`; return status and `content-type`, `content-length`, `content-range`, `accept-ranges`, `etag`, `last-modified`; other paths 404; client disconnect cancels the channel stream.
- Image screen: `FileKind {markdown, image, video}`, `fileKindOf`, `projectFile(root, path)` (replaces `projectMarkdown`); `MarkupLayer` and `MarkupToolbar` (four tools, five colours, undo, Comment, close) in `lib/media/markup.dart`; `renderMarks(source, w, h, shapes)` (white under source, JPEG q90 via `image` in `compute`, PNG layer, x0.75 until both <= `markMaxBytes = 25 MiB`); `agentImage` (longest edge <= 1568, PNG unless over 3.5 MB then JPEG 0.9); `prepareMediaComment` posts `/marks/<id>/frame.jpg`, `/marks/<id>/layer.png`, `/attach`, deleting `/marks/<id>` on failure. Anchor box uses contained-box maths (letterboxing); `version` = the `/file` ETag.
- Video screen (`lib/files/video_screen.dart`, `lib/media/frame.dart`, Kotlin `nb/frame`): `frameAt(url, at)` via `MediaMetadataRetriever.getFrameAtTime(us, OPTION_CLOSEST)` returning PNG; play/pause, scrubber with a tick per comment (tap seeks and pauses, shows its shapes); Mark up pauses and grabs the frame; anchor `time` is the paused position in seconds (ms precision) with the frame's width/height. `pubspec.yaml` adds `video_player` (dev `video_player_platform_interface`).

## Review focus

- A shape drawn on the phone lands where the desktop draws it (arrow head, stroke width, pen simplified under `PEN_MAX_VALUES`).
- The send carries every pending comment's images with the desktop's labels; a refused send leaves them pending.
